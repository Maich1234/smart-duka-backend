Each stack reports Cannot read properties of undefined (reading createCollection), originating from SubscriptionPlan model compilation and Mongoose Model.init(). This is an observed backend failure, not evidence of a phone connection or login failure.

The app disables command buffering before importing models, but left automatic collection creation enabled. Mongoose attempted createCollection with no driver DB during cold-start imports and retained the rejected init promise. The launch-pricing read later awaited that same promise, so repeated requests on the instance failed even after a database handle was available.

Disable autoCreate beside bufferCommands before model registration. Pricing revision setup now calls createCollection explicitly for SubscriptionPlan and PricingRevision after the request's database-connection middleware, instead of relying on Model.init. Preserve the durable pricing marker, concurrent in-flight sharing, production-only mutation gate, transaction boundaries, failed-attempt retry and existing access/billing calculations. Do not fabricate a free/active subscription on error or hide renewal failures. Existing index management remains separate.
